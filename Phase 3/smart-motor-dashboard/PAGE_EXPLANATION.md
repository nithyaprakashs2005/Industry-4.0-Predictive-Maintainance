# Smart Motor Dashboard - Page Explanation

This document explains each page of the Smart Motor Dashboard project in detail.

## 1. Dashboard Page
The Dashboard is the main landing page of the application. It gives a complete overview of the current condition of the monitored motor. This page displays important metrics such as:
- Motor speed (RPM)
- Temperature
- Torque
- Vibration
- Overall motor health

It also includes visual charts, alert summaries, recent fault history, AI recommendations, and motor information. In short, the Dashboard acts as the central control panel for monitoring the system.

## 2. Motors Page
The Motors page shows an overview of all the motors being monitored. It helps the user understand the general condition of the motor fleet. This page groups motors into statuses such as:
- Healthy
- Warning
- Critical

This makes it easy to see which motors are operating normally and which ones need attention. It is useful for managing multiple motors from one place.

## 3. Live Monitoring Page
The Live Monitoring page focuses on real-time monitoring. It displays live data for a selected motor and shows the current values of important parameters such as RPM, temperature, torque, and vibration. It also includes a health gauge so the user can instantly see the motor’s condition.

This page is especially useful for operators who need to monitor equipment continuously and detect abnormal behavior quickly.

## 4. Analytics Page
The Analytics page is used for historical analysis and trend observation. Instead of showing only current values, it allows users to study motor performance over a period of time. This page contains charts and summary statistics such as:
- Average temperature
- Maximum vibration
- Average RPM
- Total faults
- Average health score

It helps users identify long-term patterns and understand whether a motor is becoming less reliable over time.

## 5. Predictive Maintenance Page
The Predictive Maintenance page is designed to predict possible future issues before they happen. It uses current data and prediction logic to estimate the risk level of each motor. This page shows:
- High-risk motors
- Medium-risk motors
- Low-risk motors
- Predicted fault type
- Recommended actions

This page is important because it supports preventive maintenance and helps teams avoid unexpected breakdowns.

## 6. Fault History Page
The Fault History page provides a detailed record of previous faults and maintenance events. Users can search and filter faults based on:
- Severity
- Motor ID
- Status
- Date

Each fault entry contains useful details such as the fault name, motor involved, parameter affected, and the action taken. This page helps users track recurring problems and review previous incidents.

## 7. Reports Page
The Reports page allows users to generate and export reports about motor performance and system condition. It provides summaries of:
- Motor performance
- Fault history
- Maintenance activities
- Health status

Users can view, print, or export reports as CSV files for documentation or sharing with other stakeholders.

## 8. Settings Page
The Settings page allows the user to customize the system according to their requirements. This page includes options to change:
- Monitoring thresholds
- Simulation settings
- Update intervals
- Alert and notification preferences

It makes the dashboard flexible and adaptable for different industrial environments.

## Summary
Each page in the project has a specific purpose:
- Dashboard: main overview of motor health
- Motors: summary of all monitored motors
- Live Monitoring: real-time motor tracking
- Analytics: historical trend analysis
- Predictive Maintenance: future fault prediction
- Fault History: past fault records
- Reports: report generation and export
- Settings: system configuration and customization
